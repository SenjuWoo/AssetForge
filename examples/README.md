# Examples

The small fixtures in `assets/` are generated by this project and contain no third-party artwork:

- `triangle.glb` — one node, one material.
- `textured-scene.glb` — two nodes, two materials, one embedded texture.
- `source.png` — 256×256 RGBA image.

## Inspect and export a GLB

```bash
assetforge init demo
cd demo
assetforge run glb-inspect --input ../assets/textured-scene.glb
assetforge validate <asset-id>
assetforge export <asset-id> --target godot
```

`validate` checks structure and, when the Khronos validator is installed, runs the official check too. `export` writes a package plus `IMPORT.md`; it always reports engine import as `NOT_TESTED`.

## Optimize without destroying structure

```bash
assetforge run glb-optimize --input ../assets/textured-scene.glb
```

Requires glTF-Transform. The source and optimized manifests are compared; node, mesh, material, image and triangle counts should match. Simplification and texture compression are disabled.

## Prepare an image

```bash
assetforge run image-prep --input ../assets/source.png --set format=webp --set width=512
```

## Inspect the job and manifest

```bash
assetforge status --last
assetforge inspect <asset-id>
```

## Regenerate fixtures

From the repository root:

```bash
python -c "import sys; sys.path.insert(0,'tests'); from helpers import *; from pathlib import Path; Path('examples/assets').mkdir(parents=True, exist_ok=True); make_glb(Path('examples/assets/triangle.glb')); make_textured_glb(Path('examples/assets/textured-scene.glb')); make_png(Path('examples/assets/source.png'), size=(256,256))"
```
